# ONG Esperança

Projeto Front-End desenvolvido para a ONG Esperança, com o objetivo de apresentar projetos sociais, campanhas de doação e possibilitar o cadastro de voluntários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- WebP para otimização de imagens
